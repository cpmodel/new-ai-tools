# Version notes: MacroFiscalModels

## v0.1 (2026-10-20)
- First version: GIMF-lite, DIGNAD-lite, LIC-DSF-lite, the NMIM bridge and the demo.
- Pitch deck (`Docs/MacroFiscalModels_Pitch_v0_1.pptx`) and four user guides (`Docs/UserGuide_*.docx`, Markdown sources alongside), generated by `Docs/build_pitch.js` and `Docs/build_docs.sh`.
- Integration: `integrated.py` (dashboard -> NMIM -> PriceFeasibility -> macro model -> LIC-DSF-lite), `pricing_bridge.py`; budget need split into capital and spending; GIMF-lite gains `g_extra` and `rev_extra`; DIGNAD-lite gains `prog_spend`, `rev` and the DIGNAR-lite resource block (`rents0`, `gov_take`, `rents_path`) with a numerical terminal steady state; DIGNAR-lite routing in `calibration.py`; dashboard Appendix C (macro-model inputs) and Appendix D (integrated scenario).
- Country tool: `build_country_tool.py` -> `CountryTool/MacroFiscal_CountryTool_v0.1.xlsx`; `integrated.run_all` also writes `integrated_paths.csv` and `integrated_settings.csv`; results gain the pricing F1-F3 and abatement.

## 2026-10-20: solver speed, dashboard data, cross-check
- `pf_solver.jacobian` assembles the sparse Jacobian in one go (about 6x faster, same results).
- Calibration reads public investment from the dashboard (IMF ICSD); LIC-DSF-lite uses CPIA-based debt-carrying capacity and the IDS external share of public debt.
- `integrated.py` also runs the other model family (`alt_*` columns and paths).
- DIGNAD-R Excel v0.3 and the country tool v0.3, rebuilt on the re-run.
