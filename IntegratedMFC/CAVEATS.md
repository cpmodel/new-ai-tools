# CAVEATS: Integrated MF-C tool

Task log, newest at the bottom. Earlier entries may be corrected but not deleted.

## 2026-10-20 - Integrated MF-C tool v0.1: investment needs in the macro-fiscal dashboard
- **Task:** New tool, the Integrated MF-C (macro-fiscal climate) tool, in its own folder; first module integrates the mitigation investment needs with the macro-fiscal dashboard.
- **Inputs:** `TaxMacroFiscalDashboard/build/output/global_data_long.csv` and `config/` (v1.2 panel); `InvestmentNeeds/Mitigation_Investment_Needs_v1.1.xlsx` (cached values of Results_Country and Calc); `InvestmentNeeds/national_model/results/nmim_summary_v0_2.csv`.
- **Outputs:** `Integrated_MFC_Tool_v0.1.xlsx`; `build/build_mfc_tool.py`; `build/config/{tool.json, investment_needs_indicators.csv, investment_needs_sources.csv}`; `build/output/investment_needs_long.csv`; README, VersionNotes. `TaxMacroFiscalDashboard/build/scripts/build_dashboard.py` gains optional `tool.json` overrides and an optional `block_kind` config column, so one builder makes both workbooks; the dashboard's own output is unchanged (rebuilt and compared cell by cell: values, fonts, fills, number formats).
- **Checks:** Recalculated in LibreOffice: Kenya shows 91 of 91 indicators; v1.1 sector rows sum to incremental investment (1.11 vs 1.12% GDP, rounding); P1-P5 sum to net zero investment (2.30 vs 2.31); budget need = P1 + 0.3 x P4; private share = (P3 + P5 + 0.7 x P4) / total.
- **Caveats:** (1) Investment blocks are model output with their models' caveats (Tier 3 allocation in v1.1; judgement-based typology shares in NMIM). (2) v1.1 and NMIM disagree on the 2030 need (different methods and price bases); both shown, labelled. (3) The v1.1 extractor reads cached values, so the workbook must be recalculated after a rebuild. (4) TWN dropped (not in the dashboard country list). (5) Investment scores are percentile ranks of magnitudes, not verdicts; block averages for Investment 1-2 are as fragile as those of the Context blocks.

## 2026-10-20 - Integrated MF-C tool v0.2: NMIM only, public investment needs
- **Task:** Use NMIM for the investment needs (drop the v1.1 workbook from the tool) and add a public investment needs view.
- **Inputs:** `InvestmentNeeds/national_model/results/nmim_summary_v0_2.csv`; dashboard PEFA PI-11 and income group (v1.2 panel); IMF (2015) efficiency gaps and the PEFA mapping as in the v1.1 workbook.
- **Outputs:** `Integrated_MFC_Tool_v0.2.xlsx` (v0.1 to `Archive/`); `build/build_mfc_tool.py` (NMIM-only extractor); `build/config/{investment_needs_indicators.csv, investment_needs_sources.csv, tool.json}`; `build/output/investment_needs_long.csv`; README, VersionNotes.
- **Checks:** Recalculated in LibreOffice: Kenya 94 of 94 indicators; budget need = P1 + P4 gap (0.377 + 0.219 = 0.596% GDP); private capital = P3 + P5 + 70% of P4; incremental budget need equals Appendix D's budget need to rounding (max 0.005 pp, 186 countries). The P4 public share (0.30) is recovered from NMIM's results and checked to be the same for every country, not restated.
- **Caveats:** (1) Type shares and the 30% P4 gap are judgements (NMIM v0.2 caveats). (2) PSRT market structure ends 2013. (3) PIMA adjustment applies the efficiency gap to the whole budget need; PEFA PI-11 for 82 countries, income-group gaps elsewhere. (4) The typology splits investment, not incremental cost. (5) Earlier caveats on v1.1 (entry above) no longer apply to the tool.

## 2026-10-20 - Integrated MF-C tool v0.3: macro-fiscal module (integrated run and live DIGNAD-R)
- **Task:** Include the DIGNAD (and GIMF, DIGNAR, LIC-DSF) models in the integrated tool, building on the simple model that exists.
- **Inputs:** `MacroFiscalModels/results/integrated_{results,paths}.csv` (integrated run, 186 countries); `MacroFiscalModels/ExcelDIGNAD/build_dignad_excel.py` (DIGNAD-R equations, assumptions, augmented-input defaults, input loader and Python copy of the equations, imported, not copied); dashboard panel.
- **Outputs:** `Integrated_MFC_Tool_v0.3.xlsx` (v0.2 to `Archive/`); `build/macro_live.py` (Macro, Macro_assumptions, Macro_model, Macro_inputs sheets); `build/build_mfc_tool.py` (macro-fiscal extractor; modules can replace dashboard blocks, macro-fiscal replaces Appendix D; post-build step); `build/config/macro_fiscal_{indicators,sources}.csv`; `build/output/macro_fiscal_long.csv`; tool.json, README, VersionNotes; `MacroFiscalModels/TODO.md` item 22 marked done.
- **Checks:** Recalculated in LibreOffice with the Dashboard set to Kenya, Angola, Liberia, United States, India, Bangladesh, Nigeria and France: the live sheet equals DIGNAD-R's Python copy of the equations (`macro_live.py --check`) to 5e-7 on GDP vs 2024, GDP vs baseline and debt with and without the programme, 2030 and 2050; Kenya, Angola and Liberia also match the DIGNAD-R Excel README check (0.25% / 75.0, -22.8% / 108.8, 0.73% / 72.9). Kenya shows 102 of 102 indicators. A first build had the model table one column off (programme read as zero); found by this check and fixed.
- **Caveats:** (1) Illustrative calibrations; DSF coefficients and thresholds unchecked against the Guidance Note. (2) DIGNAD-R is DIGNAD-type for every country, recursive, one fiscal instrument, no energy savings: well below the integrated run for GIMF-lite countries (USA 2050 GDP +0.2% vs +3.8%) and different where the rule had to tighten (Liberia debt 2050 73% vs 100%). (3) Four DIGNAD-R inputs are income-group defaults. (4) Two countries are not financeable under the fiscal rule in the integrated run and have no macro results; the DSF covers 66 low and lower-middle income countries. (5) The integrated run is pre-computed: rebuild it (about 10 minutes) after NMIM or the panel change. (6) Checked in LibreOffice, not Excel.
