# AI Tools Quick Start

Two separate guides. Pick the one you need.

| Guide | Tool | Folder |
|---|---|---|
| Excise diagnostic for Indonesia | Claude (deep research) | [`1_Excise_Diagnostic_Claude/`](1_Excise_Diagnostic_Claude/) |
| Add tax indicators to the dashboard | GitHub Copilot | [`2_Tax_Indicators_Copilot/`](2_Tax_Indicators_Copilot/) |

Each folder has the guide as Word, PowerPoint and Markdown, plus `PROMPTS.md` to copy from. Everything is also in [`AI_Tools_Quick_Start.zip`](AI_Tools_Quick_Start.zip).

To change the guides, edit `build_user_guide.py` and run `python user_guide/build_user_guide.py`.
