READ ME - Data Files Overview

List of Files and their locations:
- global_technoeconomic_characteristics.csv: Located in the 'Core_Data' folder. This CSV file contains techno-economic characteristics data at the global level. They include parameters such as capacity factor, capex (USD/kW), efficiency, fixed opex (USD/kW/y), variable opex (USD/kWh), WACC (%) and total lifetime (y) and construction time (y) for technologies used in the model (coa, nga, oil, nuc, hyd, wnd, sol, ore, bio, eys, bat, bat-int).

- installed capacity.csv: Located in the 'Core_Data' folder. This CSV file contains data on the installed capacity (in MW) of various energy technologies across different countries and years (2000 to 2023).

- battery_storage.csv: Located in the 'Other_Power_Data' folder. This CSV file contains capex, fixed and variable opex and lifetime data on battery storage capacities(for battery, battery interface, water electrolysis and storage tank) at the global level.

- capex_evolution.csv: Located in the 'Other_Power_Data' folder. This CSV file contains data on the evolution of capital expenditure (capex) for various technologies over time (2000 to 2050) at global level. Data is provided for different scenarios (low, medium and hidh). Yearly change in capex for solar and wind is also included fo medium and high scenarios.

- coal_retirmement.csv: Located in the 'Other_Power_Data' folder. This CSV file contains data on coal plant retirements for different countries and years (2020 to 2040).

- country_technoeconomic_characteristics.csv: Located in the 'Other_Power_Data' folder. This CSV file contains techno-economic characteristics data at the country level for various technologies (coa, nga, oil, nuc, hyd, wnd, sol, ore, bio, eys, bat, bat-int). Parameters include capacity factor, capex (USD/kW), efficiency, fixed opex (USD/kW/y), variable opex (USD/kWh), WACC (%) and total lifetime (y). 
NB: WACC and total lifetime data are not used at the moment.

- decommissioning&transmission.csv: Located in the 'Other_Power_Data' folder. This CSV file contains data on decommissioning costs and transmission costs (expressed as % of capex) for various technologies at the global level. 
NB: Transmission costs are not used at the moment. 

- max_RE_capacity_increase.csv: Located in the 'Other_Power_Data' folder. This CSV file contains data on  average and maximum annual growth capacity (in MW), and total capacity for different countries and technologies (wind and solar).

- max_RE_investment.csv: Located in the 'Other_Power_Data' folder. This CSV file contains data on maximum scale up rate (in %) for different countries and technologies (wind and solar).

- regional_technoeconomic_characteristics.csv: Located in the 'Other_Power_Data' folder. This CSV file contains techno-economic characteristics data at the regional level for various technologies (coa, nga, oil, nuc, hyd, wnd, sol, ore, bio, eys, bat, bat-int). Parameters include capacity factor, capex (USD/kW), efficiency, fixed opex (USD/kW/y), variable opex (USD/kWh), WACC (%) and total lifetime (y).
NB: Regional data is not used at the moment.
